# 🏥 Klinik-Patientenverwaltung

Ein Desktop-Anwendung für die Patientenverwaltung einer Arztpraxis/Klinik.

## ✨ Features

- 🔐 4-stelliges Passwort Schutz
- ➕ Patienten registrieren (Name, Alter, Aktennummer, Krankengeschichte)
- ✏️ Patienten bearbeiten
- 🔍 Echtzeit-Suche (Vorname, Nachname, Aktennummer)
- 💾 Automatische Datenspeicherung (JSON)
- 🎨 Modernes UI mit lila Farbschema
- 🔑 Passwortänderung möglich

## 🚀 Installation

1. **Python 3.x installieren** (falls nicht vorhanden)
2. **Projekt herunterladen oder klonen**
3. **Programm ausführen:**
```bash
python klinik.py
```
📁 Daten

Die Anwendung erstellt automatisch folgende Dateien:

passwort.json - Für das Passwort

patienten.json - Für alle Patientendaten


🖥️ Systemanforderungen

Windows / Linux / macOS
Python 3.6 oder höher
